The industrial billing implementation and price verification below were superseded by the [night-vision metering correction](night-vision-metering.md) after the owner reported faster real-world drain. The effect-ownership rule was later tightened by [powered night vision ownership](powered-night-vision.md). This record retains the original build's test evidence.

Owner-directed correction, November 3, 2026. Implemented with OpenAI Codex (GPT-6), extending the existing powered-equipment balance on the working branch based on `235524e0c8`. Earlier equipment, scanner, charging-station, tree-detection and held-model changes are preserved.

## Player behavior

Changing a worn item's JE, paid exosuit shield remainder, jetpack low-charge warning, fuel quantity or foam supply no longer counts as putting that armor on again. This covers both exosuit styles, nano/quantum armor, industrial goggles, rechargeable battery packs, electric/native/fuel jetpacks and the construction foam backpack. Actual equips from an empty slot, different items/liveries, and changes to unrelated components retain native behavior.

The bounded common mixin changes only `LivingEntity.onEquipItem`'s sound/game-event equality check. `EquipmentUpdates` compares copies with explicitly enumerated runtime resource fields removed. Equipment detection, inventory synchronization, attributes, rendering, energy use, drops and saved stacks retain their real component values. It does not mute armor sounds globally, treat every component as disposable, or hide real charge changes from the client.

Powered night vision now has one owner, `PoweredNightVision`, called once through the existing player equipment tick. It serves Vanguard/Ronin helmets, industrial goggles, nano helmets and quantum helmets. Industrial vision uses duration 400 with refresh below 240, keeping its entire powered interval above Minecraft's 200-tick flashing window. The prior industrial duration 200/refresh below 40 spent most of each cycle inside that window. Both schedules renew every 161 ticks, retaining the existing 200 JE per approximately eight seconds; activation requires 200 JE. Exosuit vision retains 2 JE/t and its 260/220 refresh schedule. Industrial helmet tooltips explain activation, darkness, charging and toggle state.

Vision activates automatically in darkness with charged, enabled equipment. It refreshes steadily, hands over when helmets change, and releases only its tracked effect on removal, disabling, bright conditions, death or spectator mode. Exosuits stop when their per-tick charge is exhausted; an industrial helmet can finish its already-paid interval and stops if it cannot buy the next refresh. Potions and other vision providers are preserved and not billed. Ownership is session-local; an untracked effect loaded from saved player data expires normally rather than being guessed to belong to a helmet.

## Integration and compatibility

This is a repair to the existing electrical progression: the same producers and charging stations supply JE, existing recipes/modules unlock the same gear, and mining/combat/transport consume its powers. There is no new currency, capacity, conversion, automation loop, research gate, trade requirement, magical connection or ecology/event restriction. It adds no dependency, assets, client renderer, network packet or persisted schema. Worlds, item IDs, inventories, module fits and saved energy require no migration. Reverting the code restores the old sound/vision behavior without rewriting saves. No live-server installation, channel promotion or restart is included.
