# Horse breed art sources

Editable sources for the five horse breeds ([feature record](../../docs/features/horse-breeds.md)).
`tools/horse_breeds.py` turns them into the game's models, sizes and textures (and `--check` compares).

| Folder | Files | Source |
| --- | --- | --- |
| `icelandic/`, `mongolian/`, `shire/`, `finnhorse/` (the Giant Finnhorse), `friesian/` | `<art>_horse.bbmodel`, `<art>_saddle.bbmodel` | the horses v2 art delivery (13 November 2026, `jugcraft-horse-variants-v2.zip`), byte for byte; their provenance, previews and checks are in that delivery |
| `shire/`, `finnhorse/` | `<art>_saddlebags.bbmodel` | written by `tools/horse_breeds_art.py` for this change (Thanksgiving batch 2) |
| `pegasus/` | `pegasus_saddlebags.bbmodel` | the Pegasus's light pack, written by `tools/horse_breeds_art.py`, on the Pegasus's own rig (`art/pegasus/pegasus.bbmodel`) |

All pixels are original: the v2 breeds were painted by script by the v2 art workers; the saddlebags, pack and spawn eggs
by `tools/horse_breeds_art.py`. No Mojang or owner-library pixels.

## Units and conventions

- **Raw mesh px.** Every file keeps the editable Blockbench numbers (Modded Entity, box UV, format 4.10), the vanilla
  26.3 horse rig: the 12 bones, their names, parents and 30 degree rest rotations. Nothing is pre-scaled: in game each
  adult layer is scaled once with `MeshTransformer.scaling(1.1F)`, as vanilla's `ModelLayers.HORSE` is (Codex's 26.3
  evidence), so in-game height above the floor is 1.1 x (Blockbench y + 0.016).
- **Tack layers** (saddle, saddlebags) put their parts on groups with the horse's own origins; the generator checks
  that and adds cube-less copies of the remaining bones, so the tack moves with the horse.
- **Conversion** (Blockbench -> Minecraft): a root group's origin o is the part pivot (-o.x, 24 - o.y, o.z); a child's
  pivot is its origin minus its parent's, with x and y negated; rotations (degrees) become radians (-x, -y, z); a cube
  from f to t is `addBox(o.x - t.x, o.y - t.y, f.z - o.z, w, h, d)` with its inflate as the `CubeDeformation`; uv_offset is
  `texOffs` and mirror_uv is `.mirror()`.
- **The Giant Finnhorse's rearing rig** is code, not art: `tools/horse_breeds.py` (`BREEDS["giant_finnhorse"]["rig"]`).

None of these files has been opened in Blockbench by this change; previews are generated by a Python box renderer and
labelled as such (render-reviewed, runtime pending).
